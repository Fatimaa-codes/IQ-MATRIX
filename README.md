# IQ Testing App

A Python-based cognitive assessment app built with ipywidgets, designed to run in Google Colab / Jupyter. Won 2nd place at Governmet graduate College faisalabad's's exhibition.

## Features
- Three difficulty levels (Easy, Medium, Hard)
- Interactive question interface with live progress bar
- Score breakdown with performance remarks at the end

## Tech Used
- Python
- ipywidgets
- Google Colab

## How to run
Open `iq_testing_app.py` in Google Colab or Jupyter Notebook and run all cells.
